# 2-minute demo script (target 1:50, hard max 2:00). Burn in captions. Record the build, not slides.

Setup: Telegram open on a phone/desktop window (engineer), browser on /sim (HOD phone + status), Mailpit open in a tab. Fresh case (restart the app first). Quotes and answers use the demo buttons on /cases.

0:00-0:10  Problem. "Vinayak's buying chain is a string of manual handoffs, quotes arrive in four formats, and nobody records how vendors perform. Here is an agent that removes the handoffs. The human makes only the final call."
0:10-0:30  Capture. Option A (strongest): on /call, speak the requirement in Hindi; the agent answers in Hindi, reads it back, you say 'haan'. Option B: in Telegram, send a vague voice note: "Waterproofing for the toilets, it's urgent." Agent replies "I heard..." and asks for project/unit. Answer by text. Show it recognises the BOQ, confirms 7 of 7 item codes, flags A/B variants. No human involved.
0:30-0:45  RFQs. Show the timeline: 6 RFQs sent, two vendors flagged "not registered". Mailpit tab: real emails, only to test addresses. Say: "Real addresses are blocked in code."
0:45-1:15  Quotes. Press "Vendors email their quotes". Timeline: replies read as they arrive. Open /quotes: handwritten scan read with flags, SQM converted, GST-inclusive stripped, re-priced at tender quantities. Press "Vendors answer follow-ups": the agent had asked each vendor what was unclear; their answers update the quote. Fast-forward 24 h twice: chasers go to silent vendors.
1:15-1:35  Decision. HOD phone gets one message: recommendation, reasons, risks, buttons. Show /compare: landed cost, ranking, "rank if history ignored". Say: "Vendor history here is synthetic; the point is how it is built." Tap Approve.
1:35-1:55  The ledger. Fast-forward 60 days; in Telegram tap the three check-in answers (late, quality 2, dispute). Open /vendors: the record appears. Start a second case: the same vendor's score has dropped and the lead is gone. "One honest record changes the next recommendation."
1:55-2:00  Close. "Telegram agent, 360 of 360 fields extracted across 12 quotes, no order or payment path. Repo and live link below."

Before recording: incognito check of the deployed link; keys not visible; Mailpit cleared; voice clip under 30 s; do one dry run (the second case after fast-forward uses cached quote extractions so it is quick).
